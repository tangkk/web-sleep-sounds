设备同步

不同设备输入相同同步码，即可同步每种声音的开关、音量、总音量与定时设置。播放状态、倒计时和生成模式保存在本机，不会远程自动播放。

未连接

同步码相当于访问凭据，请不要公开分享。未连接时设置仍只保存在本机；同步需要联网。

声音由浏览器 Web Audio API 生成；首次播放需要点击按钮。建议从低音量开始。实时模式要求浏览器支持 AudioWorklet；部分手机锁屏或省电时可能暂停网页音频。本应用不是医疗或助眠疗效保证。
